# English Forge

Telegram-бот для тренировки английских слов из Google Sheets. Раз в день (или по команде) присылает 5-10 слов на перевод + предложения для практики, проверяет ответ, ведёт статистику и spaced repetition в той же таблице.

Архитектура: **Google Sheets** хранит словарь и статистику, **Apps Script** управляет логикой и связывается с Telegram + OpenAI, **OpenAI** генерирует предложения для практики.

## Установка с нуля

### Шаг 1. Создать Telegram-бота

1. Открой в Telegram **@BotFather**.
2. Команда:
   ```
   /newbot
   ```
3. Введи название (например `My Words Trainer`).
4. Введи username (должен заканчиваться на `bot`, например `my_words_trainer_bot`).
5. BotFather пришлёт **TELEGRAM_TOKEN** вида `1234567890:AAH...` - сохрани.
6. Отключи privacy mode (чтобы бот видел сообщения в группе):
   ```
   /setprivacy
   ```
   Выбери своего бота -> **Disable**.

### Шаг 2. Создать группу и добавить бота

1. В Telegram создай обычную группу (или supergroup).
2. Добавь бота в группу.
3. Сделай бота **админом** (стабильнее работают сообщения).
4. Напиши в группе любое сообщение, например `/start@username_твоего_бота` - нужно чтобы Telegram зарегистрировал группу для бота.

### Шаг 3. Узнать GROUP_CHAT_ID и USER_ID

В браузере открой (вставь свой токен):
```
https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
```

В JSON-ответе найди:
- `"chat":{"id": -100...}` - это **GROUP_CHAT_ID** (обычно отрицательное число, начинается с `-100`).
- `"from":{"id": ...}` - это **ALLOWED_USER_ID** (твой Telegram user_id).

Если ответ пустой (`result: []`) - отправь в группе ещё одно сообщение и повтори запрос.

### Шаг 4. Получить OpenAI API key

1. Зайди на [platform.openai.com](https://platform.openai.com).
2. Залогинься, пополни баланс через Billing (минимум $5).
3. API keys -> Create new secret key. Выбери:
   - Name: `English Forge`
   - Permissions: `All`
4. Скопируй ключ сразу (он показывается **один раз**, начинается с `sk-...`).

### Шаг 5. Создать Google Sheets со словами

Создай новую таблицу. На основном листе должны быть колонки:

| A (любая) | B (english) | C (russian) | D (можно transcription, не используется) |
|---|---|---|---|
| 1 | crucial | ключевой / крайне важный | /ˈkruːʃəl/ |
| 2 | to face the music | расхлёбывать последствия | |
| ... | ... | ... | |

**Важно:** колонки `english` (B) и `russian` (C) обязательные. Если в строке нет одного из них - бот её игнорирует. Транскрипция в D - для тебя, бот её не читает.

Служебные колонки (`shown_count`, `mastery_level`, и т.п.) бот **сам** создаст на отдельном листе `_service_cols` при первом запуске. Тебе их добавлять не нужно.

### Шаг 6. Открыть Apps Script

В Google Sheets:
```
Extensions -> Apps Script
```

Удали всё что там есть. Скопируй полностью содержимое файла `english project/english_forge_fixed.gs` из этого проекта и вставь в редактор. Save (Ctrl+S или Cmd+S).

### Шаг 7. Добавить Script Properties

В Apps Script:
```
Project Settings (шестерёнка слева) -> Script Properties -> Add script property
```

Добавь по очереди:

| Property name | Value |
|---|---|
| `TELEGRAM_TOKEN` | токен от BotFather (`1234...:AAH...`) |
| `ALLOWED_USER_ID` | твой user_id (число) |
| `GROUP_CHAT_ID` | id группы (например `-1003783181152`) |
| `OPENAI_API_KEY` | ключ OpenAI (`sk-...`) |
| `OPENAI_MODEL` | `gpt-4o-mini` (или другая модель) |

Опционально (можно не задавать, есть дефолты):

| Property | Default | Описание |
|---|---|---|
| `DAILY_WORDS_COUNT` | `10` | сколько слов в одной сессии |
| `DAY_ZERO_DATE` | `2026-05-25` | дата начала отсчёта Day N |
| `SHEET_NAME` | (авто) | имя основного листа со словами; если не задано - бот возьмёт первый видимый |
| `WEBHOOK_URL` | (авто) | URL деплоя; используется `setWebhook` если задан |

Save.

### Шаг 8. Deploy как Web App

В Apps Script:
```
Deploy -> New deployment -> значок шестерёнки -> Web app
```

Настройки:
- **Description:** `English Forge v1` (любое)
- **Execute as:** `Me`
- **Who has access:** **`Anyone`** <- критически важно, иначе Telegram получит 401/302

Нажми **Deploy**, разреши доступы (Allow -> Advanced -> Go to project (unsafe) -> Allow).

Скопируй **Web app URL** (заканчивается на `/exec`, не на `/dev`!). Сохрани в Script Properties как `WEBHOOK_URL`.

### Шаг 9. Установить Telegram webhook

В редакторе Apps Script:
1. В выпадающем списке функций (вверху) выбери **`setWebhook`**.
2. Нажми **Run**.
3. В Execution log должна быть строка вида:
   ```
   setWebhook response (url=...): {"ok":true,"result":true,"description":"Webhook was set"}
   ```

Чтобы убедиться: выбери функцию **`diagnoseWebhook`** -> Run. В логе будет JSON с `url`, `pending_update_count: 0`, без `last_error_message`.

### Шаг 10. Первый тест

В чате группы напиши:
```
/ping
```

Бот должен ответить:
```
✅ English Forge is alive.
chat: -100...
user: ...
```

Если ответил - поздравляю, основа работает. Если молчит - см. [Troubleshooting](#troubleshooting).

### Шаг 11. Запустить первую сессию

В редакторе Apps Script выбери функцию **`sendDailyWordsNow`** -> Run.

Это автоматически:
1. Очистит Telegram backlog.
2. Создаст листы `_service_cols`, `_english_forge_state`, `_english_forge_log` (если их нет).
3. Проинициализирует служебные колонки для всех твоих слов (mastery_level = 0 для новых, или восстановит из существующих данных при миграции со старой схемы).
4. Выберет 10 слов по алгоритму.
5. Перемешает их и попросит GPT сгенерировать предложения для практики (~5-10 секунд). В промпт вместе с английским словом передаётся его русский перевод из таблицы - GPT использует его как авторитетный источник смысла, чтобы для многозначных слов выбрать именно то значение, которое ты учишь.
6. Отправит в Telegram-группу одно большое сообщение:
   - Список 10 русских переводов в исходном порядке.
   - Каждый со скрытым английским ответом под `<tg-spoiler>` (тап раскрывает только один спойлер).
   - Список 10 практических предложений с пропусками `_____` в **перемешанном** порядке.

### Шаг 12. Ответ и Review

Ты отвечаешь в чате одним сообщением - пронумерованным списком ответов **в порядке practice** (т.е. отвечаешь на 1-ое предложение Practice, 2-ое и т.д.):

```
1. emergency fund
2. light up like fairgrounds
3. confabulation
4. in essence
5. ideation
6. ...
```

Правила парсинга гибкие:
- Можно отвечать **в любом порядке**: `3. word`, потом `1. word`, потом `5. word`.
- Можно **пропускать номера** - пропущенные засчитаются как `❌ Not sent`.
- Можно отправить **что угодно** хоть `xyz` - бот построит Review с 0 правильными.
- Главное чтобы хоть одно сообщение от тебя ушло в группу.

Бот через несколько секунд пришлёт **Review + Overall Stats** одним сообщением:
- Для каждой строки practice: предложение с подставленным правильным словом (жирным), твой ответ, правильный ответ, перевод.
- Распределение слов по уровням `L0-L5`.

После этого сессия автоматически очищается, и через `sendDailyWordsNow` (или cron) запустится следующая.

### Шаг 13. (Опционально) Ежедневный триггер

В Apps Script:
```
Triggers (часы слева) -> Add Trigger
```

Настройки:
- **Function to run:** `sendDailyWordsCron`
- **Event source:** Time-driven
- **Type of time-based trigger:** Day timer
- **Time of day:** например `09:00 - 10:00`

Save. С этого момента бот каждый день в указанное время сам пришлёт новую сессию.

## Как работает выбор слов

Каждое слово имеет **mastery_level** от 0 до 5:

| Уровень | Статус | Когда показывается снова |
|---|---|---|
| **0** | NEW - никогда не показывалось | завтра |
| **1** | STRUGGLING - пытался, провалил | завтра |
| **2** | LEARNING - начинает закрепляться | через 3 дня |
| **3** | JUST KNOWN - первый раз перешло в "знаю" | через 7 дней |
| **4** | KNOWN - устойчиво знаю | через 14 дней |
| **5** | MASTERED - долгосрочная память | через 30 дней |

### Переходы по уровням

- **Правильный ответ:** уровень `+1` (потолок 5).
- **Неправильный ответ:** уровень `-2`, но **пол 1** (не 0).

Пол 1 - ключевой момент: как только слово хоть раз попробовали, оно больше никогда не "новое". **Уровень 0 = строго "ни разу не показывалось".** Завалил новое слово -> оно сразу становится STRUGGLING (1) и попадает в приоритет, а не падает обратно в общий котёл новых.

Это значит:
- Слово на уровне 5, ошибся 1 раз -> стало 3 (всё ещё KNOWN).
- Ошибся 2 раза подряд -> упало до 1 (STRUGGLING, выпадает из known).
- Новое слово (0) завалил -> стало 1 (STRUGGLING).
- Валишь одно и то же снова и снова -> залипает на 1 (не растёт бесконечно), пока не ответишь верно. Отбор пластичный: выучил -> уровень поднимается -> слово показывается реже.

### Веса для weighted random

В каждой сессии бот сначала отфильтровывает слова которые сегодня "due" (`next_due <= today`), потом считает вес для каждого:

```
base = 1
+ бонус по mastery_level (главный сигнал - это пластичный уровень, а не счётчик ошибок):
    L0 -> +4   (новые; реальный приток ограничен квотой, а не весом)
    L1 -> +12  <- самый высокий приоритет (слова что ты валишь)
    L2 -> +7
    L3 -> +2
    L4 -> +1
    L5 -> 0
+ days_since бонус (+1/+2/+3/+4 за 3/7/14/30 дней с последнего показа)
    ТОЛЬКО для слов с непустым last_shown - то есть реально показанных раньше.
    Ни разу не виденные слова этот бонус НЕ получают (иначе сотни новых
    слов перевешивали бы реальные завалы).
+ scale = 1 + dailyCount/20 (множитель к L-бонусам и days-бонусам)
```

Из каждого пула выбирается нужное число слов случайно, пропорционально весам.

### Состав сессии (квоты)

Вместо лотереи по всему словарю сессия собирается по квотам, чтобы основа была из заваленных слов, новые доливались понемногу, а известные изредка прилетали на проверку:

1. **Основная часть - слова, которые ты валишь** (L1-L2).
2. **Новые слова - приток ~30%**, падает до ~20% при `failing >= dailyCount` и до 1 при `failing >= dailyCount * 2` (большой завал -> меньше новых, чтобы разгребать, а не топить себя). Минимум 1, пока новые слова есть.
3. **Проверка известных - ~10%**, только если какое-то слово L3+ "дозрело" по интервалу (`next_due`).
4. Незаполненные места добиваются: ещё завал -> ещё новые -> ещё проверки. Когда завал разгребён, новые слова текут быстрее.
5. На крайний случай (пул due слишком мал) - добор из всех слов.

## Как генерируются предложения для практики

После того как слова на сессию выбраны, бот формирует JSON-payload и отправляет его в OpenAI одним запросом. Для каждого слова передаются три поля:

- `exerciseNumber` - номер по порядку,
- `answer` - английское слово/фраза из колонки B,
- `russianMeaning` - русский перевод из колонки C.

В правилах промпта `russianMeaning` объявлен **авторитетным определением** того значения, которое нужно практиковать. Это важно для многозначных слов: например, у `face` есть смысл "лицо" и смысл "столкнуться с / расхлёбывать". Без перевода GPT выбирал бы значение на свой вкус, и предложение могло уехать в сторону, не относящуюся к тому, что ты учишь.

Если в колонке C перечислено несколько значений через `/` или `,` (например, `ключевой / крайне важный`), GPT выбирает любое **одно** из них и строит предложение только вокруг этого значения - не пытается уместить все смыслы сразу.

GPT возвращает массив JSON, в каждом элементе - то же `exerciseNumber`, тот же `answer` и сгенерированное `sentence` с пропуском `_____`. Если разбор JSON падает или модель возвращает не то - конкретная строка получает заглушку `Please use _____ in this sentence.`, остальная сессия продолжает работать.

## Структура таблицы

При первом запуске `sendDailyWordsNow` автоматически создаются три внутренних листа:

### Основной лист (твой, со словами)

| B | C |
|---|---|
| english | russian |

Берётся первый видимый лист в таблице (исключая внутренние). Или можно явно задать через property `SHEET_NAME`.

### `_service_cols` (создаётся автоматически)

10 колонок, строка N соответствует строке N основного листа:

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| shown_count | correct_count | wrong_count | last_shown | last_session_id | next_due | correct_streak | interval_days | is_known | mastery_level |

- `mastery_level` (0-5) - главный показатель усвоения.
- `is_known` - производное: `1` если `mastery_level >= 3`, иначе `0`.
- Остальные - статистика по слову.

Если основной строке нет английского/русского, а в `_service_cols` остались числа - бот сам **очищает строку-сироту** при следующем запуске.

### `_english_forge_state` (скрытый)

Хранит активную сессию (JSON) - какие слова показаны, какие ответы ждём, какой phase. После Review автоматически очищается.

### `_english_forge_log`

Подробный лог работы. Каждая строка содержит timestamp, тип события (kind), детали. Туда пишутся:
- `doPost_enter` - вход в обработку webhook'а.
- `startSession`, `gpt_request`, `gpt_response`, `session_saved`, `daily_sent` - этапы сессии.
- `reply_parsed`, `reply_scored`, `review_sent` - этапы обработки ответа.
- `*_FAILED`, `*_FATAL` - ошибки.

Можно отключить запись через команду `/log` (свойство `LOG_ENABLED` = `false`).

## Troubleshooting

### Бот не отвечает в чате

1. Запусти `diagnoseWebhook` в редакторе. Смотри:
   - `url` должен заканчиваться на `/exec`. Если на `/dev` - это URL для разработки, Telegram до него не достучится. Перенастрой `WEBHOOK_URL` на правильный `/exec` URL и запусти `setWebhook` снова.
   - `pending_update_count > 0` или `last_error_message` присутствует - webhook отбивается. Самая частая причина: в Deploy -> Manage deployments **Who has access** стоит "Only myself" или "Anyone with Google account" - нужно `Anyone`. Сделай **Edit -> New version -> Anyone -> Deploy**.
2. Запусти `testDoPostLocally` - это синтетически вызывает `doPost` с `/ping`. Если в чат пришло `✅ English Forge is alive` - код работает, проблема в webhook'е.

### Бот отвечает не на твоё сообщение, а на старое

Это Telegram ретраит застрявший в очереди webhook. Запусти `dropTelegramBacklog` один раз - очередь очистится. После этого новые сессии автоматически чистят очередь на старте и после каждого Review.

### "Practice scheduled..." пришло, но Practice так и не пришёл

Не должно случаться в текущей версии (GPT вызывается синхронно в `startDailySession_`, не через триггер). Если всё же - смотри `_english_forge_log`, ищи `gpt_FAILED` или `daily_send_failed` с текстом ошибки.

### `OPENAI_API_KEY is not set` в логах

Проверь Script Properties - ключ должен быть в формате `sk-...` (или `sk-proj-...`). И на платформе OpenAI должен быть положительный баланс.

### `Telegram send failed: ... bot is not a member of the channel chat ...`

Бот не в группе или его выкинули. Добавь обратно, сделай админом.

### Хочу сбросить всё и начать заново

В редакторе запусти `resetLearningProgress`. Это обнулит всю статистику, mastery_level и DAY_ZERO_DATE. Слова в основном листе не трогаются.

Если хочется ещё более полного сброса - удали лист `_service_cols` через UI Sheets. На следующем `sendDailyWordsNow` он создастся заново пустым.

### Не хочу спамить логами

Отправь `/log` в чате - запись в `_english_forge_log` выключится. Снова `/log` - включится. Состояние сохраняется в `LOG_ENABLED` property.

### Сколько стоит OpenAI

Каждая сессия делает один запрос к `gpt-4o-mini` объёмом ~1500-2000 токенов input + ~500-1000 output. По текущим ценам это меньше $0.001 за сессию. $5 хватит на несколько лет ежедневных сессий.
